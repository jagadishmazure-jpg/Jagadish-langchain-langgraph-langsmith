# infra/bicep

| File | What it does |
|---|---|
| `main.bicep` | the same stack as Terraform: identity, registry, Key Vault, Postgres, Redis, Container Apps, optional private networking |
| `main.parameters.json` | dev parameters (the Postgres password is generated by the deploy script at run time) |

```bash
bicep build main.bicep --stdout > /dev/null
```
