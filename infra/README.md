# infra

Optional Azure templates for a self-hosted Agent Server running the capstone. Never applied from this repo.

| Folder | What it is |
|---|---|
| [terraform](terraform/README.md) | Terraform stack with offline `terraform test`, tflint and checkov |
| [bicep](bicep/README.md) | equivalent Bicep template, checked by `bicep build` |

See [docs/deployment.md](../docs/deployment.md).
